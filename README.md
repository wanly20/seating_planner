# Seating planner

Classroom seating planner for any class: drag students to desks, randomise, cold call with a question library, track who was away.

**Live:** https://wanly20.github.io/seating_planner/

- One self-contained page (`index.html`). Class lists and plans are saved in the browser only (localStorage). Nothing is sent anywhere.
- Load a class from a CSV file, or type the names in.
- Shares its class lists with the [Claro vocabulary reviewer](https://wanly20.github.io/claro_vocabulary_reviewer/) (same site origin).
- Moved out of `claro_vocabulary_reviewer` on 2026-11-08; its earlier history lives in that repo.
